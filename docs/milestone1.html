Milestone 1: a neural network that reads one cluster of ink

Yes, this is a neural network, and it is the only trained part of the system. It is given a small picture of one cluster of ink and returns letters. Finding the clusters before it, and checking its answers after it, is done by rules.

Where the network sits

Every picture below shows this cluster:

Maths

The line's baseline b and letter height s come from the rules stage, so every cluster arrives at the same size and height on the page whatever the font size was.

2. The network: shrink the height, keep the width, then read along it

Maths

Each row of P is one frame; its numbers are probabilities over the symbols plus a special "blank" and sum to 1.

Code

src/ocrl/recog/model.py 
def forward(self, x):                 # [B, 2, 48, W]
    f = self.cnn(x)                   # [B, 192, 3, W/2]
    f = f.permute(3, 0, 1, 2).flatten(2)  # [W/2, B, 576]
    f = torch.relu(self.proj(f))      # [W/2, B, 160]
    f, _ = self.rnn(f)                # [W/2, B, 320]
    return self.out(f).log_softmax(-1)

3. What comes out: one guess for every 2 pixels of width

Maths

This is CTC. A path is one symbol per frame. Many paths collapse to the same text, and the probability of the text is the sum over all of them. Training pushes that sum up for the correct text, without ever being told which frame belongs to which letter.

Code

src/ocrl/recog/decode.py, scripts/train.py 
def greedy(logp):                     # logp: [T, symbols]
    ids = logp.argmax(-1)             # best symbol per frame
    keep = ids[np.insert(ids[1:] != ids[:-1], 0, True)]  # merge repeats
    return "".join(VOCAB[i] for i in keep if i)          # drop blanks

4. How it learns: pages we render ourselves, so the answer is always known

Maths

The optimiser is AdamW. The step size rises for the first 5% of training and then falls away smoothly, which is why the loss keeps improving right to the end.

Code

scripts/train.py 
for x, widths, targets, lengths in loader:
    logp = model(x.float() / 255)
    loss = F.ctc_loss(logp, targets, widths // 2, lengths)
    opt.zero_grad()
    loss.backward()                  # how to change each weight
    clip_grad_norm_(model.parameters(), 5.0)
    opt.step(); sched.step()         # change them a little

def check(text, n_satellites):
    found = []
    if first_violation(text) is not None:
        found.append(TOUCHING)        # more than one unit here
    lo, hi = satellite_range(text)
    if n_satellites < lo:   found.append(MISSING)
    elif n_satellites > hi: found.append(EXTRA)
    return found

Results so far

What this does not show yet

  • Every page here was rendered by us and then degraded. No real scan has been tested.
  • On degraded pages the rule checks now catch a smaller share of misreads than on clean ones. Where ink has spread and dots have fused, the dot count cannot be used, and nothing replaces it yet.
  • When strokes thin and break, the broken pieces are still counted as dots, which causes some false flags.
  • Only three fonts are held out. That is enough to see the trend, not to trust the second decimal.
  • No vowel marks, no handwriting, single-column pages only.
